Token Radar ranks the 198 pre-token protocols of a frozen DefiLlama snapshot by an implied value calibrated on the snapshot's own trading protocols, and gives each one a seven-step farm plan with costs and times.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
